# RouteGuard — Security-Aware Routing & Attack-Path Analyzer

RouteGuard is an advanced, security-focused network routing engine and architecture risk analyzer built for Computer Networks, Cybersecurity, and Application/Cloud Security studies.

## Features
- **Custom Dijkstra Implementation**: Min-Heap shortest path calculation.
- **Security-Aware Routing**: Security constraint routing bypassing compromised/untrusted nodes.
- **Attack-Path Risk Engine**: Rule-based explainable risk scoring (0–100).
- **What-If Simulation**: Compromise nodes/links and compare BEFORE vs AFTER metrics.
- **Syllabus Educational Modules**: CRC-16, Bit Stuffing, Distance Vector, and Leaky Bucket.
- **JWT & RBAC**: FastAPI REST API secured with Role-Based Access Control.
